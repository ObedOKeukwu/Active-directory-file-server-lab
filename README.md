# Active-directory-file-server-lab
Designed and implemented a Windows Server 2019 Active Directory environment. Created Organizational Units, user accounts, security groups, and NTFS permissions for departmental file access. Configured SMB file sharing and verified cross-platform access from Ubuntu Linux using CIFS/Samba. Utilized dsquery tools to enumerate Active Directory objects and demonstrated role-based access control using group membership.
## Security Auditing

Configured Windows Security Auditing using Group Policy.

Features:
- Enabled Audit Object Access
- Logged successful and failed file access attempts
- Monitored Event ID 4663 in Event Viewer
- Verified access control enforcement through access-denied testing
